# 核心與背部訓練計時器

依課表自動計時的訓練程式，包含五個動作、共 15 組，**最後 5 秒會嗶嗶倒數，換動作／換組時有明顯的長嗶＋語音提示**。

單一 HTML 檔案，不需要安裝、不需要網路、沒有任何外部套件。

## 怎麼用

**電腦**：直接用瀏覽器打開 `workout-timer/index.html` 即可。

**手機**（建議，訓練時比較好用）：

1. 把這個資料夾放到任何可以開網頁的地方（GitHub Pages、Netlify、或跟電腦同網段用 `python3 -m http.server` 起一個），
   用手機瀏覽器開啟。
2. Safari／Chrome 選「加入主畫面」，之後就像一般 App 一樣開啟（全螢幕、沒有網址列）。
3. **第一次一定要先按一次「開始」或設定裡的「播放測試」**，手機才會解鎖音訊，之後嗶聲與語音才出得來。

用 `python3 -m http.server` 的例子：

```bash
cd workout-timer
python3 -m http.server 8000
# 手機連同一個 Wi-Fi，開 http://<電腦區網 IP>:8000
```

## 課表（預設值）

### 第一階段：深層核心與脊椎穩定（無脊椎壓力）

| 動作 | 組數 | 次數 | 節奏 |
| --- | --- | --- | --- |
| 1. 鳥狗式 Bird-Dog | 3 組 | 每邊 6 次 | 每下 8 秒（伸直維持 5 秒＋收回換邊 3 秒） |
| 2. 死蟲式 Dead Bug | 3 組 | 每邊 8 次 | 每下 4 秒（緩慢下降 2 秒＋收回換邊 2 秒） |

### 第二階段：背部肌力與後側鏈強化（護膝保護脊椎）

| 動作 | 組數 | 次數 | 節奏 |
| --- | --- | --- | --- |
| 3. 橋式 Glute Bridge | 3 組 | 10 次 | 每下 5 秒（頂起 1＋頂端停留 2＋下放 2） |
| 4. 彈力帶划船 Band Seated Row | 3 組 | 12 次 | 每下 4 秒（拉 1.5＋夾緊停留 1＋放回 1.5） |
| 5. 直臂懸垂肩胛拉引 Scapular Pull-ups | 3 組 | 8 次 | 每下 4 秒（下沉 1＋停留 1＋放鬆 2） |

組間休息 60 秒、動作間休息 90 秒、開始前準備 15 秒 —— 全程約 **31 分鐘**。
每個動作的畫面上都會顯示原本的動作要領，做的時候不用再翻筆記。

## 聲音提醒

| 時機 | 提示 |
| --- | --- |
| 每一段的最後 5 秒 | 每秒一聲短嗶（880 Hz），數字同時變紅 |
| 段落結束（換組／換動作／休息結束） | 兩短一長的高音嗶 ＋ 手機震動 |
| 每一組開始 | 語音：「鳥狗式，第 2 組，開始，右手左腳」 |
| 雙邊動作換邊時 | 語音：「右手左腳」／「左手右腳」，畫面同步顯示 |
| 休息開始 | 語音：「休息 60 秒，下一個動作 死蟲式」 |
| 每做一下 | 細微的「噠」聲當節拍（可關） |
| 全部完成 | 上行三聲 ＋ 語音「訓練完成」 |

嗶聲用 Web Audio API 產生（沒有音檔要載），而且是**用音訊時鐘預先排程整段**的，
所以就算手機把分頁節流，倒數嗶聲的時間點依然準確。語音用瀏覽器內建的
`speechSynthesis`（zh-TW）；若裝置沒有中文語音，關掉「語音播報」只用嗶聲即可。

右上角 🔊 可以隨時一鍵靜音。

## 操作

- **開始／暫停**：中間大按鈕，或鍵盤空白鍵
- **⏮ / ⏭**：上一段／下一段（`←` `→`）。⏮ 在該段已過 3 秒時是「回到本段開頭」
- **重來這一段**：目前這一組從頭計時
- **課表進度**：每一組都是一個方塊，做完自動打勾（當天的進度會存在瀏覽器裡，關掉再開還在）；
  點方塊可以手動打勾／取消，點 ▶ 直接跳到那一組
- **重設全部**：清空今天的勾選並回到最開始

## 可以改的設定

設定面板（會存在瀏覽器 localStorage，下次自動帶入）：

- 開始前準備時間、動作間休息
- 每個動作的：組數、每組次數（雙邊動作是「每邊」的次數）、每下秒數、組間休息
- 嗶聲、語音、每下節拍聲、震動、訓練時螢幕不熄滅（Screen Wake Lock，支援的瀏覽器有效）
- 「還原預設」回到上面那份原始課表

改動作內容（名稱、要領、分解動作提示）的話，改 `index.html` 裡最上方的 `EXERCISES` 陣列就好。

## 幾個實作細節

- 時間一律以 `Date.now()` 換算，不是累加計數，所以**不會愈跑愈慢**；手機鎖屏或切到背景一段時間再回來，
  會把中間漏掉的組別一次補完，回到正確的進度（已驗證：凍結 500 秒後仍精準落在對的段落）。
- 暫停時會取消所有已排程的聲音，繼續時重新排程剩下的部分。
- 沒有任何外部連線、不收集資料，離線也能用。
