# 十分鐘 HIIT 計時器（45–54 歲版）

五個動作、兩輪、主訓練剛好 **10:00**，加上 1 分鐘熱身與 1 分鐘緩和，全程 12 分鐘。
最後 5 秒嗶嗶倒數、換動作長嗶＋語音報下一個動作，預設走**低衝擊護膝版**。

單一 HTML 檔，不用安裝、不用網路、沒有外部套件。用法與 `workout-timer/` 相同：
瀏覽器直接開 `hiit-timer/index.html`，或丟到任何靜態空間後用手機「加入主畫面」。
**第一次先按一次「開始」或「播放測試」**，手機才會解鎖音訊。

## 課表

```
熱身 1:00  ─ 原地踏步 / 肩臂繞環 / 髖關節繞環，各 20 秒
主訓練 10:00 ─ 2 輪 × 5 動作 × (40 秒動 + 20 秒休)
緩和 1:00  ─ 慢走 / 大腿前側 / 腿後與下背，各 20 秒
```

| # | 標準版 | 低衝擊版（預設） | 練到 |
|---|---|---|---|
| 1 | 開合跳 | 側點步開合（腳不離地） | 全身・心肺 |
| 2 | 胯下擊掌 | 抬腿胯下擊掌（不跳） | 核心・協調 |
| 3 | 彎腰提膝 | 扶椅彎腰提膝 | 腹斜肌・腰線 |
| 4 | 高抬腿 | 原地快速踏步 | 心肺・下肢 |
| 5 | 深蹲 | 椅子蹲 | 臀腿・肌力 |

畫面上永遠同時顯示另一個版本的做法，右下「切換標準版／低衝擊版」可以隨時一鍵換，不用進設定。

### 為什麼是 40 秒動 / 20 秒休、兩輪

2:1 的動休比對 45–54 歲是「心率推得上去、又來得及回落」的區間；
三個強度預設（30/30 入門、40/20 標準、45/15 進階）**主訓練都剛好 10 分鐘**，
想調整強度不必重算時間。輪數可改 1–6 輪，總長會自動更新。

## 聲音提醒

| 時機 | 提示 |
|---|---|
| 每段最後 5 秒 | 每秒一聲短嗶，數字變橘紅 |
| 進入動作 | 兩短一長的高音（1320→1760 Hz）＋ 語音「側點步開合，開始」 |
| 進入休息 | 兩短一長的低音（740→988 Hz）＋ 語音「休息，下一個 椅子蹲」 |
| 每輪開頭 | 語音加報「第 2 輪」 |
| 動作做到一半 | 一聲輕短音（可關） |
| 換段落 | 手機震動 |
| 全部完成 | 上行三聲 ＋ 語音「訓練完成」 |

休息時畫面會把**下一個動作的名稱與要領**整個換上去，不用低頭找。

## 強度參考

輸入年齡後自動算出目標區間：最大心率 `220 − 年齡`，高強度段落抓 **70–85%**，
休息要降回 60% 以下再進下一段。50 歲＝最大 170、目標 119–145、休息降到 102 以下。
沒有心率錶就看畫面上的**說話測試**判斷。

## 操作

- **開始／暫停**：大按鈕或空白鍵；**⏮ / ⏭**：上一段／下一段（`←` `→`）
- **重來這一段**、**重設全部**（清除今天紀錄）
- **課表進度**：10 個方塊，做完自動打勾（當天進度存在瀏覽器），點方塊可手動勾、點 ▶ 跳到該段
- 設定可改：動／休秒數、輪數、熱身與緩和長度、低衝擊模式、嗶聲／語音／過半提示／震動／螢幕不熄滅、年齡

## 安全上限

- 每週 **2–3 次**，中間至少隔一天；和 `workout-timer/` 的核心課表錯開日子做。
- 膝蓋出現**尖銳痛**（不是肌肉痠）立刻切低衝擊模式；下背痛就停掉彎腰提膝。
- 胸悶、頭暈、喘不過來請直接停止。

## 實作細節

與 `workout-timer/` 共用同一套計時引擎：時間以 `Date.now()` 換算不累加、嗶聲整段預先排到
Web Audio 時鐘上（手機節流也不走音）、分頁被凍結後回來會把漏掉的段落一次補完
（已驗證：凍結 11 分鐘後精準落在緩和段起點，10 個區塊全數正確標記完成）。
